# 材质映射（调色盘）格式草案

一种母材质一份 JSON。调色盘按映射显示参数：分组、通用含义、拆开的分量和注释。
用户调的值另存在角色配置里，与映射无关，所以改动或删除映射不会丢失已调的值。

## 识别

- 运行时读材质的参数名列表，按 `match` 匹配：`all` 必须全有，`any` 至少有一个，`none` 一个都不能有。
- 多份都匹配时，取 `priority` 最高的那份。
- 识别不按母材质（mmtr）路径，因为运行时不好拿到。按参数特征识别，同一母材质派生出的所有 mdf2 都能认出来。
- 都不匹配时，用内置的 `generic` 兜底：只列出名字以 `Color` 结尾的 float4。
- **附加映射**（`"addon": true`）不参与上面的取舍，只要匹配就把自己的分组接在主映射后面。用于几种母材质共用的一组参数，例如 `re4_dissolve.json`，它同时用于 lilToon 和半透明的溶解版。
- 材质被某份映射认出来以后，界面上只显示映射里写了的项。没写的参数和分量都不显示，`ignore` 只是用来防止兜底映射把它们列出来。

## 顶层字段

| 字段 | 含义 |
|---|---|
| `format` | 格式版本，目前是 1 |
| `id` / `label` | 映射标识与显示名（`zh` / `en`） |
| `source` | 含义的出处（着色器源码、文档），只供维护者参考 |
| `priority` / `match` | 识别规则，见上 |
| `addon` | 附加映射，见上 |
| `enums` | 可复用的枚举，比如混合模式 |
| `sections` | 类别列表 `[{ id, label }]`，顺序就是显示顺序。界面把同一类别的组放在一起，比如主色、第二层、第三层都属于「颜色层」 |
| `groups` | 分组列表，顺序就是显示顺序 |
| `ignore` | 不显示、也不允许调的参数（AVM 自己在用的溶解进度、未使用的槽位） |

## 分组

`id`、`label`、`section`（属于哪个类别）、`tier`、`note`（分组说明，显示在组名旁的「i」里）、`needs_texture`（该贴图是空贴图时整组隐藏）、`params`。

界面版面：先分「基本」「进阶」两块（按组的 `tier`），每块里按类别排组，每个组都可以单独折叠（默认收起）。基本组里 `tier` 为 `more` 的单项，放在组内末尾的「进阶」小标题下。

## 参数项

一个参数可以拆成多项；每一项只描述它自己用到的分量。

| 字段 | 含义 |
|---|---|
| `param` | 材质参数名 |
| `kind` | `color`（取色器）、`float`（滑条）、`enum`（下拉）、`bool`（开关，写 0 / 1）、`vec`（四个分量分别编辑） |
| `channels` | 仅 `color`：`rgb`，或 `rgba`（a 分量也是颜色透明度时才用） |
| `component` | `float` / `enum` / `bool` 用哪个分量：`x` `y` `z` `w` |
| `min` / `max` / `step` | 滑条范围（软范围），缺省 0~1。旁边的数值框可以填超出它的值 |
| `hard_min` / `hard_max` | 数值框的硬范围，可选。只在着色器本身会截断时才写（例如 `LIL_Light.y` 上限 0.95）；没写就不限制 |
| `enum` / `options` | 引用 `enums` 里的名字，或者直接写选项 |
| `labels` | 仅 `vec`：四个分量各自的名字 |
| `tier` | 单项覆盖分组的 `tier` |
| `label` / `note` | 通用含义和注释。注释不直接显示，名字旁放一个「i」图标，鼠标移上去或点一下才弹出 |

由别的脚本每帧写入、改了没意义的参数（例如 `LIL_LightDir`）放进 `ignore`，不在界面上出现。

材质里没有的参数项会自动跳过，所以一份映射可以同时覆盖普通版和溶解版。

## 维护

- 着色器源码头部的 `M[n]` 注释是权威来源。`re4_liltoon.json` 就是照 `lil_toon_re4_detail.hlsl` 第 26–83 行写的。
- `re4_dissolve.json`、`re4_transparent.json` 照「RE4 溶解流光半透明材质」会话的说明写（依据 RE4 3.5 片段源码）。半透明模板里原版 `Glass_ReflectiveTransparent_Emissive` 的参数，只收了含义确认过的 BaseColor、Alpha、EmissiveIntensity 三项。
- 滑条范围只是常用区间，有一部分是按手感定的（例如边缘光菲涅尔 0.01~50、闪粉密度 1~1000、自发光强度 0~10）；需要更大的值直接在数值框里填。
- 只写确认过的含义；不确定的参数先不放进映射，界面上就不显示，不写猜测。
- 新的自定义材质：在调色盘里对它点"导出参数清单"，得到一份列出全部参数名和类型的草稿，再照着源码填含义。
