# 怪物猎人：荒野 / 崛起 - 差分管理器 (Armor Variant Manager)

基于 REFramework 的装备差分管理工具，支持《怪物猎人：荒野》和《怪物猎人：崛起》。将多个外观差分合进一个 MOD，在游戏内切换网格、材质和预设，只占用一套装备的位置。

两款游戏使用同一个通用包，启动后自动选择对应适配。

---

## 📖 使用方法（MOD 用户）

### 1. 安装本模组

1. 为当前游戏安装 [REFramework](https://github.com/praydog/REFramework)。需要网页界面时，再安装 [REFF](https://github.com/Monkeysama/REFF) 1.x，并使用 D3D12 模式。
2. 退出游戏，将通用包内的文件解压到游戏根目录（`MonsterHunterWilds.exe` 或 `MonsterHunterRise.exe` 所在的目录）。不要多套一层发布目录。
3. 确认存在 `游戏目录/reframework/autorun/ArmorVariantManager.lua`，以及完整的 `reframework/reff/plugins/monkeysama.avm`。

包内包含荒野旧弹窗与预览使用的两个 DLL、三项预览资源及许可证；在崛起中，这两个 DLL 不启动输入桥接、渲染或预览回调。无需为崛起手工删减通用包。

### 2. 使用

- 通过下方 REFF 界面或 REFramework 原生菜单打开差分管理器。
- 选择分组和预设即可切换外观；调整材质显隐后，保存为预设。

### REFF 界面

- 关闭 REFramework 菜单后，按 REFF 的打开快捷键（默认 **F8**），在插件列表选择 **差分管理器**。分组、预设和部件/材质保持原弹窗的操作顺序。
- 在页面底部打开 **设置**，主题可选 **自有主题**（默认冰青配色）或 **跟随 REFF**；后者沿用 REFF 的配色。两种主题都遵循 REFF 字号与缩放设置。
- 使用列表行最右侧的抓手直接拖动排序；键盘聚焦列表项后也可用 **Alt+↑ / Alt+↓**。分组按主预设、全局组、普通组排列，前两类不参与拖动；预设均可排序，文字 **默认** 标记不改变顺序。排序失败会还原原顺序，选中项和已应用外观保持不变。
- **主预设** 显示全部材质，并标记普通组归属、全局组和隐藏状态。已划入普通组的材质在主预设中只读，切换到所属组后编辑；分组为空时只显示空态，不自动切换部件。
- 主配置与备份不同时会显示提示。**恢复备份** 经确认后覆盖当前装备配置；**忽略** 只关闭本次会话提示，后续保存会更新备份。恢复失败时保留提示与当前配置。
- 崛起可在预设列表底部选择 **手动导入配置**，手选其他装备 JSON 或备份；确认后替换当前装备配置并立即应用，已有预设时也可导入。REF 原生防具菜单保留 **手动查找预设**；读取或保存失败时保留当前配置。
- **帮助** 中可查看完整配置说明、使用方法和原荒野版本更新记录，没有角色时也能阅读。
- 设置中的全局选项直接保存。材质显隐和荒野 **陷地修复** 属于预设草稿，调整后需新建或覆盖预设；高度控件位于 **部件材质** 右侧底部，悬停或键盘聚焦信息按钮可查看说明。
- 数值可拖动滑动条快调，也可在输入框精确填写。受击时间、次数的滑动条范围只是快调范围，不限制原配置可保存的数值；保存失败时保留输入供重试。
- 荒野勾选页面顶部的 **全身预览**，在左侧查看当前人物；镜头参数仍在 **设置** 中调整。关闭页面、切换插件或隐藏 REFF 后停止网页预览；原 Home 弹窗与网页共用一台预览相机。
- 网页全身预览需要支持 **原生预览接口 v1** 的 REFF 和本包的 `ArmorVariantManager_Portrait.dll`，目前只支持游戏 SDR 输出。升级 REFF 时成套更新其 DLL 与宿主 EXE；旧版 REFF 不影响原有预设管理和 Home 弹窗预览。
- 荒野安装时同时保留 `ArmorVariantManager_UI.dll` 与 `ArmorVariantManager_Portrait.dll`：前者显示原弹窗，后者负责独立预览、模型姿态和 GPU 资源。
- 原生菜单入口保持不变：在 REFramework 的 **Script Generated UI** 中展开差分管理器。没有安装 REFF 也能使用该入口；荒野原 Home 弹窗暂时保留。
- 原有 JSON 无需转换，仍从当前游戏的 `reframework/data/ArmorVariantManager` 读取和保存。

### 3. 常见问题

- **预设丢失**：使用盒子等工具更改了套装会导致当前预设失效，在当前套装无预设时会出现自动查找预设按钮，点击即可重新匹配预设。
- **自己保存的预设被覆盖掉了**：原因：盒子等 MOD 管理工具在启用/禁用 MOD 时会把所有 MOD 都重新装一遍。现在差分管理器会创建备份文件，如果检测到备份文件冲突，会提示还原备份，点击即可还原你自己的预设。
- **掉帧/卡顿**：荒野可在设置中调整扫描间隔、装备缓存时间和扫描批量；扫描较慢可降低扫描开销，但换装后的更新也会更慢。崛起若只管理自己，可在联机设置中关闭“为其他玩家应用差分”。

### 4. 升级、回退与卸载

升级前退出游戏，备份 `reframework/data/ArmorVariantManager`（包含 `backup` 子目录）及当前 AVM 程序文件。原 JSON 按当前游戏的装备 ID 继续读写，无需转换，也不要将两款游戏的数据目录互相覆盖。

将以下旧 AVM 程序项移到游戏加载目录之外，再解压新通用包；不要把 `.bak.lua` 等副本留在 `autorun` 中：

```text
reframework/autorun/ArmorVariantManager.lua
reframework/autorun/ArmorVariantManager_Core/
reframework/autorun/ArmorVariantManager_UI/
reframework/plugins/ArmorVariantManager_UI.dll
reframework/plugins/ArmorVariantManager_Portrait.dll
reframework/plugins/AVM_InputBridge.dll              # 旧崛起版本，存在时移出
reframework/reff/plugins/monkeysama.avm/
natives/STM/ArmorVariantManager/Portrait/
```

保留用户数据、REFramework、REFF 及其他 MOD，尤其不要删除共享的 `reframework-d2d` 插件。包内 `LICENSE`、`licenses/` 和网页许可证应随程序保留。

- **回退**：退出游戏，移出新版本的上述程序项，恢复备份的程序；需要恢复旧配置时，再使用升级前的数据备份。
- **卸载**：退出游戏，移出上述 AVM 程序项。保留数据目录可供以后重装；不再需要预设时自行归档或删除。

## 🛠️ 使用方法（MOD 作者）

### 1. 当前防具/武器部件

可以查看当前装备的材质列表，左侧的勾选框可操控当前装备的材质对应网格的显示/隐藏。

### 2. 预设

在材质列表中调整显隐，在预设列表下方输入名称，点击 **保存预设**；已有同名预设时会覆盖它。选择预设会立即应用。默认启用“将选中预设设为默认”；关闭后可用 **设为默认** 单独保存下次加载时的选择。

### 3. 默认分组

界面中的 **主预设** 是不可删除的默认分组，最初拥有全部材质。材质划入普通组后仍在主预设列表中展示归属，但只能在所属组中编辑。

- 适用于整套装备只有少量材质变化，或者所有材质都是统一切换的场景：比如整套防具只有一个简单的"显示/隐藏披风"需求。

### 4. 分组

点击 **新增分组** 进入材质选择状态，勾选材质、输入名称，再点击 **创建分组**。取消会退出选择，不创建分组。荒野必须至少选择一项材质；崛起保留允许空分组的用法。

- 分组**会**将选中的材质从默认分组里抽离出来，这部分材质控制权交给对应的分组。
- 在主预设中，能够看到材质被哪个分组占用。
- 适用于同一套装备有多个独立部位需要分别管理，且它们之间互不影响：比如腰部装饰有"长裙/短裙/无"3种，腿部有"长靴/短靴"2种 → 分别建组，互相独立切换。

### 5. 全局分组

点击新增分组时，在下方勾选全局分组，即可进入新增全局分组模式，操作与分组一样。

- 全局分组**不会**将选中的材质从默认分组里抽离出来，其他分组仍然能选择和控制全局分组里的材质。
- 全局分组具有最高的**隐藏优先级**，即被全局分组隐藏的，在任何状态下始终保持隐藏。
- 被全局分组隐藏的材质在其他分组下仍可被勾选，但仅记录状态，不会进行显示/隐藏替换。
- 适用于跨越多个分组的统一控制：比如分组里的例子上加上红黄蓝三种配色，那使用普通分组则需要分 3×3+2×3 种预设，这时则可以将换色这个功能放进全局分组内。

### 6. 变身管理

基础预设管理基础上的功能，可以根据游戏内的不同条件动态操控预设变化。

- 在 REFF 页面底部打开 **条件变换**，选择条件后，为对应状态添加目标分组和预设；修改后自动保存。两款游戏分别显示各自支持的条件。
- 启用 **并行模式** 可同时配置多个条件，分别调整启用状态和优先级；崛起另有变身总开关。
- 荒野的受击条件支持普通、循环与链式模式；链式节点可分别设置持续时间和目标预设。生命值与受击测试会直接修改当前玩家的生命值。
- 变身管理具有回退功能，以血量触发为例，当血量低于 80 时从 A 变为 B，那当血量高于 80 时自动回退到 A。
- 多状态并行时，优先级数字越小则表示优先级越高。

### 7. 预设文件

- 保存的预设会在 `reframework\data\ArmorVariantManager` 文件夹内。
- 防具和武器均以界面显示的装备 ID 命名，两款游戏的 ID 格式不同。荒野防具以身体（Body）部位为准，比如 `ch03_060_0002.json`。
- 武器直接记录当前武器 ID，荒野示例为 `it0300_0020`。

### 8. 陷地修正（界面中为“陷地修复”）

- 仅荒野：用于高跟鞋穿脱等外观切换时的高度修正。在 REFF **部件材质** 右侧底部调整当前装备草稿，信息按钮支持悬停和键盘聚焦说明；REF 原生界面位于预设管理内部。默认关闭，可调整 -10～50 cm。
- 调整后实时预览，新增或覆盖当前分组预设时保存勾选状态与高度。只有勾选的预设参与高度控制，未勾选保留当前高度；多个分组依次应用时，以最后应用的勾选预设为准。要从 +10 cm 恢复到 0 cm，请切换到勾选且高度为 0 cm 的预设；“归零”按钮也会勾选并设为 0 cm。默认加载和变身规则同样跳过未勾选的预设，变身条件结束后仍回退到手动基线。
- 支持本机显示的玩家、菜单/存档/捏脸等预览和过场玩家模型，按各自防具读取预设；人物与所属武器一起抬升。加载切场及骑乘鹭鹰龙时暂停。
- 仅修正本机显示的骨架高度，不改变物理坐标、碰撞或其他玩家客户端。兼容旧 JSON，未配置的旧预设默认关闭。

## 从源码生成发布包

使用 Python 3.10 或更新版本运行发布脚本。脚本使用仓库中的 Lua、已构建 DLL 和 REFF 页面，生成一个同时支持两款游戏的通用包；包含本说明，不包含用户配置、原生/Web 开发源码或调试文件，也不捆绑 REFramework / REFF 本体。

```powershell
# 生成一个通用包，游戏在运行时自动识别
python build_release.py

# 指定输出目录，避免覆盖已有发布产物
python build_release.py --output-dir ./output
```

- 默认产物为 `release/ArmorVariantManager_v<版本>` 和 `release/差分管理器_v<版本>.zip`，REFF 清单同时声明 `MHWILDS` 与 `MHRISE`。
- 包内保留完整 Lua 库存与旧 `require` 入口，启动时只创建当前游戏的运行服务。荒野保留旧 Home 弹窗与独立预览；对应 DLL 在崛起中不启动。
- 同名产物已存在时默认不覆盖；确认要替换时添加 `--overwrite`。
- 旧自动化显式使用的 `--game wilds`、`--game rise`、`--game all` 仍保留原构建含义；日常构建无需指定游戏。
