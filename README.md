# 差分管理器 (Armor Variant Manager)

基于 REFramework 的装备差分管理工具，支持《怪物猎人：荒野》和《怪物猎人：崛起》。将多个外观差分合进一个 MOD，在游戏内切换网格、材质和预设，只占用一套装备的位置。

两款游戏使用同一个通用包。
## 安装

1. 为当前游戏安装 [REFramework](https://github.com/praydog/REFramework)。
2. 退出游戏，将通用包解压到游戏根目录。

## 打开与使用

### REF 原生菜单

打开 REFramework 菜单，在 **Script Generated UI** 中展开 **差分管理器**。

- 选择防具或武器，再选择分组和预设切换外观。
- 调整材质显隐后，新建或覆盖预设保存。选择预设会立即应用；默认自动将选中预设设为当前分组默认值。
- 在 **变身管理** 中配置条件变换；荒野的高度草稿位于预设管理内。
- 崛起防具菜单中的 **手动查找预设** 可选择其他装备的 JSON 或备份，读取或保存失败时保留当前配置。

### REFF 网页界面（可选）

需要独立网页界面时，另行安装 [REFF](https://github.com/Monkeysama/REFF) 。
关闭 REFramework 菜单后，按 REFF 打开快捷键（默认 **HOME**），在插件列表选择 **差分管理器**。

## 常见问题

- **换套装后预设消失**：盒子等工具更改了装备 ID 后，当前套装可能没有对应文件。使用自动查找预设，或在崛起中手动导入原配置。
- **MOD 管理器覆盖了自建预设**：管理器重新安装 MOD 时可能替换主配置。出现备份冲突提示后，可选择恢复；以后升级前先备份数据目录。
- **掉帧或卡顿**：荒野可增大扫描间隔、装备缓存时间，或减小扫描批量；开销降低后换装响应也会变慢。崛起若只管理自己，可关闭 **为其他玩家应用差分**。

## MOD 作者配置

### 1. 当前防具/武器部件

可以查看当前装备的材质列表，左侧的勾选框可操控当前装备的材质对应网格的显示/隐藏。

### 2. 预设

在材质列表中调整显隐，在预设列表下方输入名称，点击 **保存预设**；已有同名预设时会覆盖它。选择预设会立即应用。默认启用“将选中预设设为默认”；关闭后可用 **设为默认** 单独保存下次加载时的选择。

### 3. 默认分组

界面中的 **主预设** 是不可删除的默认分组，最初拥有全部材质。材质划入普通组后仍在主预设列表中展示归属，但只能在所属组中编辑。

- 适用于整套装备只有少量材质变化，或者所有材质都是统一切换的场景：比如整套防具只有一个简单的"显示/隐藏披风"需求。

### 4. 分组

点击 **新增分组** 进入材质选择状态，勾选材质、输入名称，再点击 **创建分组**。取消会退出选择，不创建分组。荒野必须至少选择一项材质。

- 分组**会**将选中的材质从默认分组里抽离出来，这部分材质控制权交给对应的分组。
- 在主预设中，能够看到材质被哪个分组占用。
- 适用于同一套装备有多个独立部位需要分别管理，且它们之间互不影响：比如腰部装饰有"长裙/短裙/无"3种，腿部有"长靴/短靴"2种 → 分别建组，互相独立切换。

### 5. 全局分组

点击新增分组时，在下方勾选全局分组，即可进入新增全局分组模式，操作与分组一样。

- 全局分组**不会**将选中的材质从默认分组里抽离出来，其他分组仍然能选择和控制全局分组里的材质。
- 全局分组具有最高的**隐藏优先级**，即被全局分组隐藏的，在任何状态下始终保持隐藏。
- 被全局分组隐藏的材质在其他分组下仍可被勾选，但仅记录状态，不会进行显示/隐藏替换。
- 适用于跨越多个分组的统一控制：比如分组里的例子上加上红黄蓝三种配色，那使用普通分组则需要分 3×3+2×3 种预设，这时则可以将换色这个功能放进全局分组内。

### 6. 变身管理

基础预设管理基础上的功能，可以根据游戏内的不同条件动态操控预设变化。

- 在 REF 原生菜单打开 **变身管理**，或在可选 REFF 页面底部打开 **条件变换**，为对应状态添加目标分组和预设；修改后自动保存。两款游戏分别显示各自支持的条件。
- 启用 **并行模式** 可同时配置多个条件，分别调整启用状态和优先级；崛起另有变身总开关。
- 荒野的受击条件支持普通、循环与链式模式；链式节点可分别设置持续时间和目标预设。生命值与受击测试会直接修改当前玩家的生命值。
- 变身管理具有回退功能，以血量触发为例，当血量低于 80 时从 A 变为 B，那当血量高于 80 时自动回退到 A。
- 多状态并行时，优先级数字越小则表示优先级越高。

### 7. 预设文件

- 保存的预设会在 `reframework\data\ArmorVariantManager` 文件夹内。
- 防具和武器均以界面显示的装备 ID 命名，两款游戏的 ID 格式不同。荒野防具以身体（Body）部位为准，比如 `ch03_060_0002.json`。
- 武器直接记录当前武器 ID，荒野示例为 `it0300_0020`。

### 8. 陷地修正

- 仅荒野：用于高跟鞋穿脱等外观切换时的高度修正。在 REFF **部件材质** 右侧底部调整当前装备草稿，信息按钮支持悬停和键盘聚焦说明；REF 原生界面位于预设管理内部。默认关闭，可调整 -10～50 cm。
- 调整后实时预览，新增或覆盖当前分组预设时保存勾选状态与高度。只有勾选的预设参与高度控制，未勾选保留当前高度；多个分组依次应用时，以最后应用的勾选预设为准。要从 +10 cm 恢复到 0 cm，请切换到勾选且高度为 0 cm 的预设；“归零”按钮也会勾选并设为 0 cm。默认加载和变身规则同样跳过未勾选的预设，变身条件结束后仍回退到手动基线。
- 支持本机显示的玩家、菜单/存档/捏脸等预览和过场玩家模型，按各自防具读取预设；人物与所属武器一起抬升。加载切场及骑乘鹭鹰龙时暂停。
- 仅修正本机显示的骨架高度，不改变物理坐标、碰撞或其他玩家客户端。兼容旧 JSON，未配置的旧预设默认关闭。
