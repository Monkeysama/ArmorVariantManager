# 溶解过渡

差分切换时，使用溶解模板的材质按溶解动画消失或出现，其他材质照常瞬间切换。本文面向制作溶解材质和差分配置的 MOD 作者。

## 材质参数

差分管理器只在材质带有 `Dissolve_Rate` 变量时播放溶解。模板需要按下表读取这两个变量：

| 变量 | 分量 | 含义 |
|---|---|---|
| `Dissolve_Rate` | x、y、z | 溶解比例，0 为完整，1 为全部消失。三个分量写入同一个值 |
| `Dissolve_Rate` | w | Reversing：0 时从溶解图低值处（中心）开始消失，1 时从高值处（外圈）开始 |
| `Dissolve_Flag` | y | IsMorphed：为 1 时可见判定反转，用于出现方。没有 `Dissolve_Flag` 的模板也能溶解，只是不支持原地互换 |
| `Dissolve_Flag` | x、z、w | 差分管理器不修改，保持 mdf 中的值 |

动画结束后，消失方的材质被关闭，两个变量均恢复为动画开始前读取的值。mdf 中这两个变量的默认值应当对应"完整显示"。

《荒野》支持以下模板：`Wilds_LIL_Toon_Dissolve`、`Wilds_LIL_Toon_AnimDissolve`、`Wilds_BlendAlpha_Dissolve`、`Wilds_BlendAlpha_AnimDissolve`。

## 出现方式

| 方式 | 写入 | 效果 | 模板要求 |
|---|---|---|---|
| 原地互换 | 消失方与出现方同时把比例从 0 推到 1，出现方 IsMorphed = 1 | 新外观在旧外观消失的位置长出，两者互补 | 支持 IsMorphed |
| 倒放 | 出现方比例从 1 退到 0，IsMorphed = 0 | 出现是消失的倒放 | 只需 `Dissolve_Rate` |

《荒野》在模板支持 IsMorphed 时使用原地互换，其余溶解模板使用倒放。

原地互换还区分方向：前进时比例 0 → 1，Reversing = 0；后退时比例 1 → 0，Reversing = 1，消失方 IsMorphed = 1，出现方为 0。倒放不区分方向。

动画进行中再次切换时，保留当前遮罩，并从当前比例反向继续：原动画走过 30% 时，反向动画用时为时长的 30%。

## 《荒野》的配置

### 条件规则

在 REF 的「变身管理」或 REFF 的「条件变换」中，打开防具的目标规则，勾选「启用溶解过渡」，再设置进入和退出时长。旧规则默认关闭，两项时长默认均为 0.5 秒。时长设为 0 时，对应方向瞬间切换。受击链式模式使用该条受击规则的设置。

配置文件使用以下字段：

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `dissolve_enabled` | 布尔 | `false` | 这条规则引起的切换播放溶解 |
| `dissolve_hide_time` | 秒 | `0.5` | 进入这个状态时的溶解时长 |
| `dissolve_show_time` | 秒 | `0.5` | 离开这个状态、回到默认外观时的溶解时长 |

```json
"spirit_transform_rules": [
  { "level": 3, "targets": [ { "group": "", "preset": "红刃" } ],
    "dissolve_enabled": true, "dissolve_hide_time": 0.8, "dissolve_show_time": 0.5 },
  { "level": 4, "targets": [ { "group": "", "preset": "满刃" } ],
    "dissolve_enabled": true, "dissolve_hide_time": 1.2 }
]
```

生效的预设目标变化时，覆盖该分组的规则决定过渡。并行规则造成多个新预设目标生效时，使用这些目标中优先级最高的规则。

- 有新预设目标生效时，使用对应规则的 `dissolve_hide_time`。通常前进，同一规则列表中从较后的规则回到较前的规则时后退，例如气刃等级 4 → 3。
- 只有目标结束时，使用原先生效规则的 `dissolve_show_time` 后退。多个目标同时结束时，使用退出前优先级最高的规则。
- 决定过渡的规则没有开启 `dissolve_enabled` 时，瞬间切换。
- 生效的预设目标不变时，正在播放的动画会继续。

### 界面切换

在界面上切换预设、分组预设，或勾选部件、材质时，按全局设置溶解：

| 设置 | 默认 | 含义 |
|---|---|---|
| `ui_dissolve_enabled` | `true` | 界面切换播放溶解 |
| `ui_dissolve_time` | `1.0` | 溶解时长（秒），范围 0–30 |

关闭界面溶解或将时长设为 0 时，当前界面过渡也会立即结束并还原材质参数。

### 瞬间切换的情况

- 不使用溶解模板的材质。
- 武器：条件规则与界面编辑武器时都瞬间切换。
- 进入场景或换装后的首次应用。
- 时长为 0。

### 部件

规则或界面关闭整个部件时，当前可见的溶解模板材质一起溶解，结束后关闭部件；打开部件时先应用材质显隐，再让可见的溶解材质出现。部件上没有溶解模板材质时直接开关。
