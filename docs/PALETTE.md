# 调色

预设可以附带一组材质参数覆盖：选中这个预设时，差分管理器把覆盖值写到对应材质上；不再使用时写回原值。本文面向在预设里发布调色的 MOD 作者。

## 字段

预设新增可选字段 `palette`：

```json
"presets": {
  "暗色": {
    "0": { "materials": { "cloth": true } },
    "palette": {
      "0": {
        "cloth": { "BaseColor": { "x": 0.2, "y": 0.2, "z": 0.25 }, "Roughness": 0.8 }
      }
    }
  }
}
```

- 第一层是部位，键与预设里的部位相同：防具为 `"0"`–`"5"`，武器为对象序号。
- 第二层是材质名，第三层是参数名。
- float 参数写数值。float4 参数写 `{ "x", "y", "z", "w" }` 中要改的分量，没写的分量保持材质当前的值。
- 只支持 float 与 float4 参数。
- `Dissolve_Rate`、`Dissolve_Flag` 由溶解过渡控制，`LIL_LightDir` 由 lilToon 的光向脚本每帧写入，写在这里不生效。
- 没有 `palette` 的预设不受影响；覆盖保存预设时保留原有的 `palette`。

## 生效规则

- 默认组、普通组、全局组的预设都可以带 `palette`，条件规则切到的预设同样生效。
- 多个预设写同一个参数时，按材质开关的合成顺序覆盖：主列表、普通组、条件规则目标、全局组，后写的生效。float4 按分量覆盖。
- 原值是差分管理器第一次写这个参数之前材质上的值。换装、读档后重新记录。
- 被覆盖的参数每帧检查，被其他插件改写时恢复为覆盖值；没有覆盖的参数差分管理器不修改。

## 与 MDF-XL 同时使用

MDF-XL 在载入预设、换装和打开特定游戏界面时整份写入材质参数。

- 差分管理器没有覆盖的参数保持 MDF-XL 写入的值。
- 差分管理器覆盖的参数以差分管理器为准：MDF-XL 重写后，下一帧恢复为覆盖值。
- 取消覆盖时写回差分管理器记录的原值。MDF-XL 在记录之后才改过这个参数时，写回的是 MDF-XL 改之前的值，直到 MDF-XL 下次重写。

## 导出材质预设与写入 mdf2

《荒野》中，调好的材质可以带出差分管理器，需要随包附带的原生插件 `ArmorVariantManager_Portrait.dll`。只能读写游戏目录 `natives/` 下的松散 mdf2 文件；打包在 pak 里的材质只能导出，不能写入。

### 导出材质预设

把一个材质存成 RE Mesh Editor 的材质预设：`reframework/data/ArmorVariantManager/mdf2_presets/MHWILDS/<名字>.json`。拷进 RE Mesh Editor 的 `Presets/MHWILDS/` 目录后，可以在 Blender 中套用到材质上。

- 参数取当前值，包括调色覆盖后的值。
- 材质头、Flags、贴图、MMTRS 与 GPBF 取自 MOD 的 mdf2。读不到 mdf2 时只用游戏里能拿到的参数和贴图，母材质路径与 Flags 留空，需要在 Blender 中补齐。
- 名字只能用英文字母、数字、空格、`-` 和 `_`，最多 64 个字符。

### 写入 mdf2

把某个预设在一个部位的调色覆盖直接写进该材质所在的 mdf2，本局立即生效。

- 只改参数值所在的字节，文件结构不变。第一次写入前，原文件备份为 `<文件>.avm_bak`，之后的写入不再改动这份备份。要还原，退出游戏后用备份替换原文件。
- 写进文件的参数会从该预设的 `palette` 中删除：它们已成为材质原值，所有预设、所有使用这个 mdf2 的角色都会用到。
- 用 Fluffy 等 MOD 管理器卸载 MOD 时，管理器只删除它安装的文件，`.avm_bak` 与下面的重载副本可能残留在 `natives/` 中，需要手动删除。

为了让本局立即生效，差分管理器会在同一目录写一份重载副本 `<名字>_avmr<数字>.mdf2.<版本>` 并换上（同一路径的资源游戏不会重新读取）。本局之内副本不会删除：模型重建时会按副本路径重新加载，文件不在会导致整个模型不显示。重启游戏时，上一次启动留下的副本会被删除；重置脚本不算重启。
