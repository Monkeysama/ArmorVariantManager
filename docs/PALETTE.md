# 调色

预设可以附带一组材质参数覆盖：选中这个预设时，差分管理器把覆盖值写到对应材质上；不再使用时写回原值。本文面向在预设里发布调色的 MOD 作者。

## 字段

预设新增可选字段 `palette`：

```json
"presets": {
  "暗色": {
    "0": { "materials": { "cloth": true } },
    "palette": {
      "0": {
        "cloth": { "BaseColor": { "x": 0.2, "y": 0.2, "z": 0.25 }, "Roughness": 0.8 }
      }
    }
  }
}
```

- 第一层是部位，键与预设里的部位相同：防具为 `"0"`–`"5"`，武器为对象序号。
- 第二层是材质名，第三层是参数名。
- float 参数写数值。float4 参数写 `{ "x", "y", "z", "w" }` 中要改的分量，没写的分量保持材质当前的值。
- 只支持 float 与 float4 参数。
- `Dissolve_Rate`、`Dissolve_Flag` 由溶解过渡控制，写在这里不生效。
- 没有 `palette` 的预设不受影响；覆盖保存预设时保留原有的 `palette`。

## 生效规则

- 默认组、普通组、全局组的预设都可以带 `palette`，条件规则切到的预设同样生效。
- 多个预设写同一个参数时，按材质开关的合成顺序覆盖：主列表、普通组、条件规则目标、全局组，后写的生效。float4 按分量覆盖。
- 原值是差分管理器第一次写这个参数之前材质上的值。换装、读档后重新记录。
- 被覆盖的参数每帧检查，被其他插件改写时恢复为覆盖值；没有覆盖的参数差分管理器不修改。

## 与 MDF-XL 同时使用

MDF-XL 在载入预设、换装和打开特定游戏界面时整份写入材质参数。

- 差分管理器没有覆盖的参数保持 MDF-XL 写入的值。
- 差分管理器覆盖的参数以差分管理器为准：MDF-XL 重写后，下一帧恢复为覆盖值。
- 取消覆盖时写回差分管理器记录的原值。MDF-XL 在记录之后才改过这个参数时，写回的是 MDF-XL 改之前的值，直到 MDF-XL 下次重写。
